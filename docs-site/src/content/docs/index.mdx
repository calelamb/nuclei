This is the developer and researcher documentation for [Nuclei](https://nuclei.dev),
the free, open-source IDE for learning quantum computing. If you want to *use*
Nuclei, [download the app](https://nuclei.dev/#download) or
[try it in the browser](https://nuclei.dev/try/) — this site is for people
**building on** Nuclei.

## Find your path

- **Contributing to the IDE?** Start with the [architecture](/docs/introduction/architecture/)
  and [install &amp; build](/docs/introduction/install-and-build/) pages.
- **Talking to the kernel from your own client?** Head to the
  [Kernel API overview](/docs/kernel-api/overview/).
- **Adding a quantum framework or hardware backend?** See
  [framework adapters](/docs/extending/framework-adapters/) and
  [hardware providers](/docs/extending/hardware-providers/).
- **Curious how the AI assistant works?** Read the
  [Dirac architecture](/docs/dirac/architecture/).

## Protocol versioning

These docs describe **kernel protocol v1**, the WebSocket protocol shipped with
Nuclei 0.5.x. Breaking protocol changes will be versioned and tracked in the
[protocol changelog](/docs/reference/protocol-changelog/).
